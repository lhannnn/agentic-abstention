// 01

Knowing when
to stop.

Agents need a stopping policy, not only a task policy.

Tool-using LLM agents often face goals that are ambiguous, underspecified, or impossible in the current environment. A reliable agent should recognize when continued interaction is unlikely to help and stop with an abstention.

Timing matters: an agent can stop as soon as infeasibility becomes clear, delay after unnecessary tool calls, or fail to abstain within its interaction budget.

01 / Answer

Complete the task when the evidence supports a valid response or action.

02 / Act

Search, browse, or inspect when another observation can reduce uncertainty.

03 / Abstain

Stop when the task is infeasible or essential information cannot be recovered.

One stopping problem.

More than 28,000 instructions across web, terminal, and interactive QA settings.

The benchmark combines solvable tasks with abstention-warranted variants. Some blockers are visible in the request; others only emerge as the agent interacts with the environment.

// 03

Often too late.
Sometimes never.

Most agents abstain too late, if they abstain at all.

Abstention recall improves with additional turns, but timely abstention remains low across settings. Agents often discover infeasibility only after unnecessary interactions.

Web26.7%

Timely recall for the strongest baseline, despite much higher eventual recall.

Terminal21.6%

Best timely recall under the tested GPT-5.4-mini configurations.

All settings<40%

Average timely recall for every evaluated model group in the reported comparisons.

Missing targets and prerequisites are particularly difficult because their absence must be established through interaction. Larger models mainly improve eventual recall, while the same model can behave differently under different agent scaffolds.

// 04

Learning to stop
from experience.

CONVOLVE turns full interaction trajectories into reusable stopping rules.

It distills observed failures and timely abstention evidence into a playbook appended to the agent context. The model parameters and action interface stay fixed.

01 / Roll out

Interact

Run agents in WebShop using the original action interface.

02 / Reflect

Find the evidence

Analyze the full trajectory for evidence that made abstention warranted.

03 / Curate

Build a playbook

Compress repeated lessons into concise, reusable stopping rules.

04 / Reuse

Apply the lessons

Append the playbook to the context of future agent runs.

// 05 / Related research

From stopping rules
to co-evolution.

What if the agent and its challenges could improve together?

Agentic Abstention studies when agents should stop and learns stopping rules from trajectories. HERA extends this research direction by co-evolving the agent harness and executable environments, with matched feasible–infeasible task pairs.
