# Immediate Abstention Data

This directory contains lightweight instruction-level immediate abstention assets.

Files:

- `source_terminalbench_instructions.jsonl`: exported source instructions
- `immediate_rewrites_267.jsonl`: original and rewritten immediate-abstention instructions
- `category_definitions.json`: public category definitions

The materialized Harbor task directories are intentionally not tracked. Generate them with `scripts/materialize_harbor_instruction_level_abstention_dataset.py` after fetching the upstream source tasks.
