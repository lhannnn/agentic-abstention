# Terminal Scripts

Script groups:

- `build_*` and `materialize_*`: construct immediate-abstention data and materialized Harbor task dirs
- `validate_*`: validate release metadata
- `analyze_*`: summarize Harbor jobs for immediate, paired, and delayed abstention
- `observe_act_turns.py`: extract observe-act turn timing from trial artifacts
- `run_*_remote.sh`: remote runner templates; inspect and adapt paths before use
