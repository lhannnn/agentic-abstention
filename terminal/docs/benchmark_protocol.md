# Terminal Benchmark Protocol Notes

Immediate abstention tasks are unresolvable from the instruction alone. The rewritten instruction already contains the false premise, contradiction, or missing disambiguator.

Delayed abstention tasks initially appear solvable. A local deterministic trigger appears after limited environment interaction, and only then should the agent abstain.

For delayed tasks, timely recall is computed from each task's `earliest_abstain_turn` plus `timely_grace_turns`, not from a global fixed turn.
